# SMSEagle SMS & Voice Call Driver for Niagara 4

A free driver that connects Tridium Niagara 4 to an [SMSEagle](https://smseagle.eu) hardware SMS gateway.
Use it to send SMS notifications and make voice calls straight from your Niagara station.

## Features

- Send SMS messages from Niagara 4 through an SMSEagle device
- Make voice calls through an SMSEagle device
- Free to use under the MIT License

## Documentation

Installation, configuration and usage are described in the driver manual:
[Proximus_Niagara_SMS_driver_v3.3.pdf](Proximus_Niagara_SMS_driver_v3.3.pdf)

## Need more advanced features?

This repository contains the basic SMSEagle driver for Niagara 4.
If your project needs more advanced functionality, we recommend the Niagara4 driver from our partner **Smart Node**.
Learn more: [Niagara 4 SMS integration](https://www.smseagle.eu/integration-plugins/niagara-4-sms-integration/)
